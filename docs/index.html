Set it up once.

Calibrate A and B, then let the Windows listener run quietly in the background and start at login.

From small remote to first prompt.

Windows 10/11 · Chrome 116+ · Python 3.12+ · ChatGPT dictation · Microphone

  1. Download the ZIP and extract it into a permanent folder.
  2. Run setup.ps1 to install dependencies and create your local pairing token.
  3. Load the extension folder in Chrome's developer-mode extensions page.
  4. Open the control window once to calibrate your gamepad.
  5. Open ChatGPT, allow the microphone when requested, and press B.
